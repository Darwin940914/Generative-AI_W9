UVa 10035 - Primary Arithmetic

題目在問什麼

每筆測資給兩個正整數（最多 10 位數），模擬小學直式加法從個位數一路往左加，算總共會發生幾次「進位」。當輸入的兩個數字都是 0 時結束程式。

解題思路

不用轉成字串，直接用迴圈每次取兩個數字的個位數（a % 10 跟 b % 10），再加上前一位留下來的進位值 carry。只要加起來大於等於 10，進位次數就加 1，然後把 a 跟 b 各自除以 10 繼續算下一位，直到兩個數都變成 0 為止。

時間複雜度為 $O(\log_{10}(\max(a, b)))$，每筆測資最多跑 10 次迴圈。

C++ 程式碼

#include <iostream>
using namespace std;

int main() {
    long long a, b;
    while (cin >> a >> b) {
        if (a == 0 && b == 0) {
            break;
        }

        int carry = 0;
        int count = 0;

        // 從個位數開始逐位相加，直到兩數都處理完
        while (a > 0 || b > 0) {
            int digit_a = a % 10;
            int digit_b = b % 10;
            int sum = digit_a + digit_b + carry;

            if (sum >= 10) {
                carry = 1;
                count++;
            } else {
                carry = 0;
            }

            a /= 10;
            b /= 10;
        }

        if (count == 0) {
            cout << "No carry operation.\n";
        } else if (count == 1) {
            cout << "1 carry operation.\n";
        } else {
            cout << count << " carry operations.\n";
        }
    }

    return 0;
}

易錯點

  • 輸出單複數不同：進位 1 次時是 1 carry operation.（沒有 s），2 次以上才是 operations.，0 次則是 No carry operation.，拼錯直接吃 WA。
  • 終止條件：題目允許其中一個數是 0（例如 0 999），所以不能寫 while (a || b) 當作輸入結束條件，必須明確判斷 if (a == 0 && b == 0) break;。
  • 數值範圍：題目說少於 10 位數，開 long long 最保險，避免極端測資溢位。
